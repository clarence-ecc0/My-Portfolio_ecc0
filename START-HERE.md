## 📊 SYSTEM OVERVIEW

```
Admin Panel                Portfolio Website
    ↓                           ↓
  Save                        Load
    ↓                           ↑
    └─→ localStorage ←──────────┘
          "portfolio_projects"
          (JSON array)
```

**Data Flow:**
1. You add project in admin
2. Saves to browser localStorage
3. portfolio-sync.js reads from storage
4. Renders on portfolio automatically
5. Real-time sync enabled
