## 🖼️ Image Guidelines

### File Format
- **Format:** JPG or PNG
- **Size:** 1200-1500px width recommended
- **Compression:** < 500KB per image
- **Aspect Ratio:** 16:9 for cover, consistent for gallery

### Upload Tips
- Drag & drop from file explorer
- Preview loads automatically
- Remove with × button
- Multiple gallery images at once
- Compressed images = faster loading

## 🐛 Troubleshooting

### "Incorrect PIN"
- Try default: `1234`
- Clear browser cache (Ctrl+Shift+Del)
- Try incognito window
- Check caps lock

### Projects Don't Appear
- Refresh portfolio (Ctrl+F5)
- Check category matches filter
- Verify localStorage not disabled

### Images Won't Upload
- Compress file < 5MB
- Try JPG format
- Check file not corrupted
- Different image if still issues

### Can't Access Admin
- Verify URL is `/admin.html`
- Not `/index.html`
- Check browser supports localStorage

### Data Lost
- Import from backup JSON
- Check different browser (separate storage)
- Ask for help

## 🔄 Typical Workflow

**Every time you complete a project:**

```
1. Take screenshot / export design
2. Compress image (< 500KB)
3. Access /admin.html
4. Enter your PIN
5. Click ➕ Add New Project
6. Fill in title, category, description
7. Upload cover image
8. Add tags (optional)
9. Click 💾 Save
10. Done! Project appears on portfolio
```

**When updating a project:**

```
1. Go to 📋 Manage Projects
2. Find project
3. Click ✏️ Edit
4. Change details/images
5. Click 💾 Save
6. Changes appear instantly
```

**Weekly maintenance:**

```
1. Go to ⚙️ Settings
2. Click 📥 Export Data
3. Save JSON file to backup location
4. Done! Data is safe
```

## 🌟 Pro Tips

1. **Organize Images**
   - Use consistent naming: `ProjectName-page1.png`
   - Compress before upload
   - Test gallery order before saving

2. **Use Good Descriptions**
   - Help visitors understand your work
   - Include tools/technologies used
   - Mention client or purpose

3. **Strategic Tags**
   - Use consistent tag names
   - Make tags searchable
   - Examples: "Brochure", "Logo", "Website"

4. **Regular Backups**
   - Export after adding projects
   - Store in multiple places
   - Test restore process

5. **Category Consistency**
   - Use same category for similar work
   - Helps with portfolio filtering
   - Looks organized to visitors
