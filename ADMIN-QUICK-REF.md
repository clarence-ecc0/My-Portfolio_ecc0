# ⚡ Admin Panel Quick Reference

## 🔐 Access
- **URL:** `/admin.html`
- **PIN:** `1234` (change immediately!)

---

## 🎯 Main Views

| Icon | View | Purpose |
|------|------|---------|
| ➕ | Add New Project | Create/edit projects |
| 📋 | Manage Projects | View, edit, delete all projects |
| 👁️ | Live Preview | See all projects as displayed |
| ⚙️ | Settings | Export/import, PIN, data management |

---

## 📝 Adding a Project - 5 Steps

```
1. Fill Title & Category
2. Write Description
3. Upload Cover Image (drag & drop)
4. Choose: Single or Multi-Image
5. Add Tags → Save
```

---

## 🖼️ Project Types

**Single Image:** Logo, poster, graphic → View Full Size  
**Multi-Image:** Brochure, pitch deck → Gallery (11 images)

---

## 💾 Data Backup

```
Export: Settings → Export Data → Save JSON file
Import: Settings → Import Data → Select JSON file
```

---

## 🔑 Change PIN

```
Settings → Change PIN → 
Enter current (1234) → 
New 4-digit PIN → 
Confirm → Update
```

---

## 🎨 Image Tips

- **Cover:** 1200-1500px wide, < 500KB
- **Gallery:** Same dimensions, consistent aspect ratio
- **Format:** JPG or PNG
- **Aspect:** 16:9 recommended

---

## ⌨️ Quick Keys

- `Enter` - Submit form
- `Esc` - Close modals/gallery
- `←/→` - Navigate gallery images
- `Ctrl+Shift+Del` - Clear browser cache

---

## 🚨 Troubleshooting

| Problem | Solution |
|---------|----------|
| PIN doesn't work | Try `1234` or clear cache |
| Projects don't show | Refresh page (Ctrl+F5) |
| Image won't upload | Compress < 5MB, try JPG |
| Gallery broken | Select Multi-Image type, upload images |
| Data lost | Import from backup JSON |
