About Me

I'm a creative learner exploring frontend and software development, with hands-on skills in HTML, CSS, UI/UX (Figma), graphic design (Canva, Adobe), and programming in Python, C++, and PHP.

Design isn’t just what you see — it’s how it performs.

As an aspiring Software Developer, I build a strong foundation in programming with Python, C++, and PHP. I enjoy solving real-world problems through logical thinking and efficient code, with a growing interest in developing scalable, user-focused applications.

As a Graphic Designer, I create visually compelling content including logos, social media designs, and marketing materials using tools like Adobe Photoshop, Illustrator, and InDesign. I focus on blending creativity with clear communication to deliver impactful designs.

As a Frontend Web Developer, I design and build responsive, user-friendly interfaces using HTML and CSS, while expanding my skills in JavaScript and modern tools. With a passion for UI/UX design, I create intuitive layouts and prototypes using Figma and Adobe XD, bringing ideas to life through clean and engaging web experiences.
